# Contributing

```bash
pip install -e ".[dev,surrogate,mcp]"
ruff check src tests scripts recipes
pytest -q --cov=sciagent
```

- **New simulator**: follow `docs/ADDING_A_SIMULATOR.md`; add numerical tests (a convergence order or a closed
  form) next to `tests/test_numerics.py`, and a reference with `scripts/compute_references.py`.
- **New planner**: subclass `sciagent.planners.base.Planner`; it only *proposes*. Do not touch budget accounting.
  Add it to `make_planner` and to the resume test in `tests/test_resume_redirect.py`.
- **Changing simulator results** requires bumping that simulator's `version` (invalidates caches) and recomputing
  the references and the committed results (`sciagent experiments --profile cpu-full --results results/cpu`).
- **Notebooks** are generated: edit `notebooks/build_notebooks.py`, then run it.
- Results in the README and `docs/TECHNICAL_REPORT.md` are generated by `sciagent report`; do not edit numbers by hand.
